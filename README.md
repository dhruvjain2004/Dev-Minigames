# dev-minigames 🎮✨

![Mini Games Banner](https://via.placeholder.com/1000x300?text=dev-minigames+%7C+Build+Fun+One+Game+at+a+Time)

Welcome to **dev-minigames** — a collection of interactive, bite-sized games built for fun, learning, and sharpening your development skills.

Each game is coded from scratch using web technologies and is designed to teach key concepts in programming, logic, user interaction, and animation.

## 🎯 Purpose

These projects are built to:
- Reinforce **JavaScript fundamentals**
- Practice **DOM manipulation**, **event handling**, and **game loops**
- Learn **game design principles** on a small scale
- Explore **animation**, **keyboard control**, and **timing**
